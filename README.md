# AI-Chat-Bot

A privacy-focused offline AI chatbot that runs entirely on your local machine using Ollama and locally hosted Large Language Models (LLMs).

Unlike cloud-based AI applications, this chatbot does not require an internet connection or external AI API after the required model has been downloaded. Conversations and prompts can be processed locally, making it suitable for users who value privacy, security, and offline access.

🌐 Overview

The Offline AI Chatbot provides a ChatGPT-like conversational experience while keeping AI inference on the user's own computer.

The application communicates with a locally running Ollama server, which manages and executes the selected AI model.

✨ Features
🤖 Local AI
Runs AI models locally using Ollama.
No external AI API required.
Supports multiple Ollama-compatible models.
AI inference happens on the user's machine.

🔒 Privacy First
Conversations can remain completely local.
No prompts need to be sent to third-party AI services.
No cloud AI subscription required.
Suitable for sensitive or private conversations.

💬 Chat Interface
Real-time conversational interface.
User and AI message separation.
Message timestamps.
Loading indicators.
Markdown response support.
Code block formatting.

⚙️ Model Selection

Switch between locally installed Ollama models.

Example:

Llama
Mistral
Gemma
Qwen
DeepSeek
Phi

The exact models available depend on the models installed on the user's machine.

📡 Offline Capability

Once Ollama and the required model are installed, the chatbot can operate without an internet connection.

Internet access is required initially to download Ollama and AI models.
